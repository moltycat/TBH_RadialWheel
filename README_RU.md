**Harmony Radial Wheel** — это настраиваемое радиальное меню, разработанное для ускорения рабочего процесса в **Toon Boom Harmony**. Оно позволяет мгновенно вызывать JS-скрипты и клавиатурные макросы через визуальный интерфейс, который появляется прямо под курсором мыши. 


---

## ✨ Основные возможности
* **Полная кастомизация**: Добавляйте любое количество радиальных колец, сегментов и подменю через встроенный графический редактор. 
* **Два типа действий**:
  1. **JS Script**: Выполнение JavaScript кода (интеграция с Harmony через файл команд). 
  2. **Keyboard Macro**: Эмуляция нажатий клавиш с поддержкой модификаторов (Ctrl, Shift, Alt). 
* **Умные хоткеи**: Возможность назначить активацию меню на любую клавишу. 
* **Визуальный редактор**: Настройка радиуса меню, имен элементов и выбор иконок (PNG). 
* **Автоматизация**: Автоматическое подтягивание иконок и названий при выборе скрипта из папки `actions`.

## 💻 Системные требования
* **ОС**: Windows
* **Среда**: Toon Boom Harmony (Premium рекомендован)
* **Язык**: Python 3.13+

## 🚀 Установка

1. **Скачивание**: Скачайте архив из [последнего релиза](https://github.com/moltycat/TBH_RadialWheel/releases/latest).
2. **Распаковка**: Распакуйте папку `HarmonyRadialWheel` в корень диска `C:\`. 
   > ⚠️ Проверка: Файл с командами должен находиться по пути: `C:\HarmonyRadialWheel\harmony_command.json`
3. **Python**: Установите Python 3.13 (или выше) с [оф. сайта](https://www.python.org/downloads/) или из папки: 
   `C:\HarmonyRadialWheel\Setup\Setup 1 python 3.13.7.exe`
4. **Библиотеки**: Выполните в консоли `pip install PySide6 pynput` или запустите:
   `C:\HarmonyRadialWheel\Setup\Setup 2.bat`
5. **Файлы Harmony**:
   * Переместите `Molty_RadialWheel.js` в папку скриптов Harmony (пример для 25ой версии TBH): 
     `%AppData%\Roaming\Toon Boom Animation\Toon Boom Harmony Premium\2500-scripts\`
   * Переместите иконку `Molty_RadialWheel.png` в: 
     `.../2500-scripts/script-icons/`
6. **Активация**: Добавьте скрипт `Molty_RadialWheel` на панель инструментов внутри Harmony.

## 🛠 Использование

1. **Запуск хоста**: Запустите скрипт внутри Harmony. Окно должно выдать: `✅RadialWheelHost started✅`.
2. Можно использовать несколько виджетов одновременно, просто назначьте их на разные клавиши.
3. **Работа**: Зажмите горячую клавишу → Наведите мышь на сектор → Отпустите клавишу.
   > ⚠️ При закрытыии окна оно сворачивается в трей, для полного закрытия нужно нажать exit в трее!

---

## ⚙️ Настройка виджета

В окне редактора вы можете:
* **Top Bar**: Настройка названия, шортката, лого и внешнего радиуса колеса
* **Add Main Item / + Sub**: Добавление основных секторов и подменю.
* **Режимы**: Выбор между JS-шаблоном и макросом.
* **Иконки**: Ручное указание пути к PNG или авто-подбор.
* **Порядок**: Изменение положения секторов стрелками.
* **Save JSON**: Сохранение настроек и применение изменений.

## 🔗 Дополнительные скрипты (NodeView)
В комплекте идут встроенные кастомные скрипты:
  1. `Molty_rename_CompPeg` - переименовывет выделенные пеги композы и деформеры. Если выделить вместе с рисунком, то присваивает его имя.
  2. `Molty_xPivot_to_0` - устанавливает координату пивота пега X на 0.
  3. `Molty_BG_Group_cleanV2` - нужно выделить группу с рисунками, автоматически входит по всем папкам и проставлят пеги к рисункам.
  4. `Molty_def_rename` - переименовывет deformation в def
  5. `Molty_composite_AP_rename` - переименовывет композ на основе подключенных к ниму нодам для созания autopatch систем
  6. `Molty_Layers_script` - позволяет выбрать шаблоны слоев под выделенным рисунком
  7. `Molty_Line_Thickness_script` - настраивает толщину линии на рендере на заданный размер пикселей. Работает в 1080p и 4k.
